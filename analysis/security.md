# T2Editor v11 보안 분석

## 보안 아키텍처

### 다층 방어 (Defense in Depth)
```
1. 클라이언트 측 검증
2. 서버 측 검증
3. 데이터베이스 측 검증
4. 출력 인코딩
```

## 주요 보안 기능

### 1. 인증/인가

#### 관리자 인증
- CMS 연동 인증 (그누보드5, 라이믹스)
- 자체 인증 (t2admin.key)
- 세션 관리

#### 권한 관리
- 역할 기반 접근 제어 (RBAC)
- IP 기반 접근 제어
- 기능별 권한 설정

### 2. XSS 방지

#### 입력 필터링
- HTML 태그 필터링
- 속성 필터링
- 이벤트 핸들러 제거

#### 출력 인코딩
- HTML 엔티티 인코딩
- JavaScript 인코딩
- URL 인코딩

### 3. CSRF 방지

#### 토큰 기반
- 세션별 토큰 생성
- 요청별 토큰 검증
- 토큰 만료

### 4. SQL Injection 방지

#### Prepared Statements
- 모든 쿼리에 prepared statements 사용
- 파라미터 바인딩
- 입력값 검증

### 5. 파일 업로드 보안

#### 파일 검증
- MIME 타입 검사
- 확장자 검사
- 파일 내용 검사

#### 파일 저장
- 안전한 파일명 생성
- 실행 방지
- 접근 제어

## 보안 모범 사례

### 코드 작성
1. **입력 검증**: 모든 입력값 검증
2. **출력 인코딩**: 컨텍스트별 인코딩
3. **최소 권한**: 필요한 최소 권한만 부여
4. **에러 처리**: 상세 에러 정보 노출 금지
5. **로깅**: 보안 이벤트 로깅

### 설정
1. **HTTPS**: 항상 HTTPS 사용
2. **CSP**: Content Security Policy 설정
3. **HSTS**: HTTP Strict Transport Security
4. **X-Frame-Options**: 클릭재킹 방지
5. **X-XSS-Protection**: XSS 필터 활성화
