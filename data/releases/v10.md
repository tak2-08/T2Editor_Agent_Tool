## v10.5.1
## 배포 설명

업데이트사항:
cms(그누보드5, 라이믹스)에서 로그인 시 cms 자동 로그인 뿐만아니라 T2Editor 자체적인 로그인이 가능하도록 기능 추가

패치사항:
그누보드5에서 cms자동 로그인을 통한 T2Editor 관리자 로그인이 불가능 한 이슈 패치

-- -- --
기능 추가:

CMS 환경의 T2Editor 자체 로그인 지원

* 그누보드5와 라이믹스에 설치한 경우에도 CMS 관리자 로그인과 별개로 T2Editor 자체 비밀번호로 로그인할 수 있습니다.
* 관리자 인증 화면에 T2Editor 자체 로그인하기 버튼을 추가했습니다.
* CMS 관리자 로그인 상태가 정상적으로 인식되지 않는 환경에서도 T2Editor 관리자 페이지에 접근할 수 있습니다.

CMS 환경의 자체 로그인 최초 설정 지원

* 그누보드5와 라이믹스 환경에서도 T2Editor 자체 로그인 설정이 완료되지 않은 경우 최초 설치 안내 화면을 표시합니다.
* admin/t2admin.key.txt 파일을 admin/t2admin.key로 변경하고 자체 관리자 비밀번호를 설정하면 자체 로그인을 사용할 수 있습니다.
* 기존 CMS 관리자 인증은 그대로 유지되며, 자체 로그인은 필요할 때 선택해서 사용할 수 있습니다.

에디터 하단 자체 로그인 기능 추가

* 에디터 하단의 정보 및 진단 화면에서 자체 로그인 설정과 로그인을 진행할 수 있습니다.
* 자체 비밀번호가 설정되지 않은 경우에는 자체 로그인 설정 버튼이 표시됩니다.
* 자체 비밀번호가 설정된 경우에는 T2Editor 자체 로그인 버튼이 표시됩니다.
* 로그인 후에는 페이지를 새로고침하지 않아도 T2E_Admin 링크가 바로 표시됩니다.

그누보드5 내부 데이터 저장 위치 정리

* 이미지와 첨부파일은 기존처럼 data/editor 폴더에 저장됩니다.
* 관리자 설정, 인증 정보, 협업 데이터, 업데이트 기록, 서드파티 설치 정보는 data/t2editor_db 폴더에 별도로 저장됩니다.
* 기존 data/editor/t2editor_db 데이터는 새 위치로 자동 이전됩니다.

라이믹스 iframe 자동 등록 경로 정리

* 라이믹스에서 T2Editor 동영상 iframe 허용 목록이 더 안정적으로 등록되도록 관련 파일 위치와 경로 계산을 정리했습니다.
* 별도 애드온 설정 없이 T2Editor 동영상 iframe이 작동하도록 하는 기존 목적은 유지됩니다.

패치사항:

그누보드5 관리자 로그인 인식 문제 해결

* 그누보드5 관리자로 로그인했는데도 T2Editor에서 그누보드5 관리자 로그인 필요 안내만 표시되는 문제가 있었습니다.
* 그누보드5 로그인 정보를 불러오는 위치가 적절하지 않아 관리자 상태가 정상적으로 전달되지 않는 것이 원인이었습니다.
* 10.5.1에서는 그누보드5 관리자 정보를 정상적으로 확인할 수 있도록 인증 초기화 방식을 수정했습니다.

CMS 환경에서 자체 로그인을 사용할 수 없던 문제 해결

* 10.5.0에서는 그누보드5나 라이믹스가 감지되면 T2Editor 자체 로그인을 사용할 수 없었습니다.
* CMS 관리자 인증이 실패하면 관리자 페이지에 접근할 다른 방법이 없었습니다.
* 10.5.1에서는 CMS 환경에서도 T2Editor 자체 로그인 화면으로 이동할 수 있도록 수정했습니다.

관리자 대시보드 무한 로딩 문제 해결

* 일부 환경에서 서버의 PHP 확장과 파일 권한을 확인하고 있습니다라는 문구와 로딩 표시가 계속 나타나고, 다른 메뉴도 클릭할 수 없는 문제가 있었습니다.
* 관리자 화면에 전달되는 일부 정보가 정상적인 문자 형식으로 변환되지 않아 화면 스크립트가 중단되는 것이 원인이었습니다.
* 10.5.1에서는 문제가 있는 문자를 안전하게 처리해 관리자 화면이 멈추지 않도록 수정했습니다.

기존 게시글 편집 시 빈 화면 문제 해결

* 오래된 게시글이나 외부에서 복사한 글에 손상된 문자가 포함된 경우 에디터가 빈 화면으로 표시될 수 있었습니다.
* 본문을 화면에 전달하는 과정에서 문자 변환이 실패하면 에디터 실행이 중단되는 것이 원인이었습니다.
* 10.5.1에서는 문제가 있는 문자만 안전하게 대체하고 나머지 내용은 정상적으로 불러오도록 수정했습니다.

협업 문서 불러오기 및 충돌 응답 오류 개선

* 협업 문서에 손상된 문자가 포함된 경우 문서 내용이나 충돌 정보가 정상적으로 전달되지 않을 수 있었습니다.
* 10.5.1에서는 협업 문서와 충돌 응답에도 안전한 문자 처리를 적용했습니다.

그누보드5 데이터 이전 문제 개선

* 기존 data/editor/t2editor_db에 있던 관리자 설정, 협업 데이터, 업데이트 기록, 서드파티 설치 정보가 새 위치로 안정적으로 이전되도록 수정했습니다.
* 이전된 설정 안에 남아 있던 과거 경로도 새 경로에 맞게 자동으로 변경됩니다.

내부 데이터 폴더 접근 보호 강화

* 관리자 인증 정보와 협업 데이터가 저장되는 내부 폴더에 직접 접근 방지 파일을 추가했습니다.
* 브라우저에서 해당 폴더 주소를 직접 입력해도 내부 파일 목록이 노출되지 않도록 보완했습니다.

중요 관리자 작업의 재인증 방식 개선

* T2Editor 자체 로그인으로 접속한 경우 업데이트, 백업 복구, 서드파티 설치 같은 중요 작업에서 자체 관리자 비밀번호를 다시 확인하도록 수정했습니다.
* CMS 관리자로 접속한 경우에는 기존처럼 CMS 관리자 권한을 기준으로 작업을 승인합니다.

버전 정보 갱신

* T2Editor 본체 버전을 10.5.1로 갱신했습니다.
* 라이믹스 스킨 정보와 배포 날짜도 10.5.1 기준으로 정리했습니다.

상세 설명:

T2Editor 10.5.1은 10.5.0에서 도입된 CMS 관리자 자동 인증과 데이터 저장 구조를 실제 운영 환경에 맞게 안정화한 업데이트입니다.

10.5.0에서는 그누보드5와 라이믹스가 감지되면 T2Editor 자체 비밀번호 대신 CMS 관리자 로그인 상태만 확인했습니다. 하지만 일부 그누보드5 또는 빌더 환경에서는 관리자로 로그인한 상태인데도 T2Editor가 이를 인식하지 못해 관리자 페이지에 들어갈 수 없는 문제가 있었습니다.

10.5.1에서는 CMS 관리자 인증을 유지하면서도 T2Editor 자체 로그인을 함께 사용할 수 있도록 개선했습니다. 이제 CMS 관리자 인증이 실패하더라도 T2Editor 자체 비밀번호를 설정해 관리자 페이지에 접근할 수 있습니다.

또한 관리자 대시보드에서 서버의 PHP 확장과 파일 권한을 확인하고 있습니다라는 문구가 계속 표시되고 다른 메뉴가 작동하지 않던 문제를 수정했습니다. 이 문제는 서버 확장 부족만의 문제가 아니라, 관리자 화면에 전달되는 일부 정보가 정상적으로 변환되지 않아 화면 스크립트가 중단되면서 발생할 수 있었습니다.

오래된 게시글이나 협업 문서에 손상된 문자가 포함됐을 때 에디터가 빈 화면으로 표시되거나 협업 응답이 실패하던 문제도 함께 보완했습니다. 문제가 있는 문자만 안전하게 처리하고 나머지 내용은 가능한 범위에서 정상적으로 불러오도록 수정했습니다.

그누보드5 환경에서는 내부 데이터 저장 위치도 정리했습니다. 이미지와 첨부파일은 기존 위치를 유지하고, 관리자 설정과 협업 데이터, 업데이트 기록 등은 별도의 내부 데이터 폴더로 분리했습니다. 기존 데이터는 새 위치로 자동 이전됩니다.

## v10.5.0
## 배포 설명

업데이트사항:
CMS 관리자 권한 연동
- 그누보드5와 라이믹스에서는 T2Editor 전용 관리자 비밀번호를 별도로 입력하는 대신, 현재 CMS의 관리자 로그인 상태를 이용해 T2Editor 관리자 권한을 확인하도록 변경했습니다. 업데이트, 서드파티 설치 등 관리자 승인이 필요한 기능도 CMS 관리자 세션을 기준으로 처리합니다.
관리자 페이지 빠른 이동
- 현재 사용자가 관리자로 확인되면 에디터 하단 버전 정보 옆에 T2E_Admin 링크가 표시됩니다. 일반 사용자에게는 링크와 관리자 경로가 노출되지 않습니다.
- 독립 실행 환경에서는 버전 정보를 눌러 여는 디버깅 패널에 ‘관리자 로그인하기’ 버튼이 추가됩니다. 이미 로그인한 상태에서는 ‘관리자 페이지 열기’로 표시됩니다.
메이저 버전 호환성 경고
- 관리자 업데이트에서 현재 T2Editor와 설치 대상으로 선택한 에디터 버전의 메이저 버전이 다르면, 버전 목록에 경고를 표시하고 업데이트 계획을 만들기 전에 관리자에게 호환성 위험을 다시 확인합니다.
- 서드파티 설치에서는 매니페스트의 지원 기준 버전(t2editor_min) 메이저 버전과 현재 T2Editor 메이저 버전이 다르면 카탈로그와 릴리즈 화면에 경고를 표시하고, 설치 승인 전에 다시 확인합니다.
- 경고 확인값을 서버에서도 검증해 확인 정보가 없는 직접 설치 요청이나 업데이트 계획이 그대로 적용되지 않도록 했습니다.
CMS 연결 구조 독립화
- 그누보드5와 라이믹스 관련 처리를 에디터 코어와 각 플러그인에 흩어 놓지 않고, CMS별 연결 계층으로 분리했습니다.
- CMS 감지, 관리자 인증, 데이터 경로, 업로드 방식과 응답 처리를 각 CMS 어댑터가 담당합니다. 기존 10.4.0의 공개 함수와 라이믹스 스킨 연결 구조는 계속 사용할 수 있도록 호환성을 유지했습니다.
- 특정 CMS 연결에서 오류가 발생하더라도 다른 CMS 처리나 에디터 전체 초기화까지 중단되지 않도록 오류 범위를 분리했습니다.
CMS별 데이터 경로 정리
- 그누보드5에서는 data/editor, 라이믹스에서는 files, 독립 실행 환경에서는 T2Editor/data를 기준으로 데이터를 관리합니다.
- 업로드 미디어를 제외한 관리자 설정, 캐시, 협업 상태, 업데이트 상태 등의 내부 데이터는 t2editor_db 아래에 모아 CMS 데이터 폴더가 불필요하게 복잡해지지 않도록 했습니다.
- 기존 위치에 저장된 데이터와 경로 정보는 가능한 범위에서 새 구조로 이전하거나 계속 인식합니다.
최초 설치 안내 개편
- 설치 권한은 777이 아니라 707을 최소 권장값으로 명확하게 안내합니다.
- 실제 PHP 파일 생성·쓰기·삭제 시험이 성공하면 현재 권한을 그대로 유지하며, 숫자로 표시된 권한만 보고 불필요한 chmod 명령을 요구하지 않습니다.
- 777도 작동 자체를 막지는 않지만 필요 이상으로 넓은 권한이므로 권장하지 않는다고 명시했습니다.
- 그누보드5와 라이믹스에서는 독립 실행 환경에만 필요한 관리자 키와 권한 설정 항목을 기본적으로 접어 두며, 사용법·운영·보안 설명도 필요할 때만 펼쳐 볼 수 있도록 정리했습니다.
브라우저 보조 ZIP 설치
- 서버에 PHP ZipArchive가 없더라도 zlib을 사용할 수 있으면 서버 내부 처리로 업데이트와 서드파티 설치를 진행합니다.
- ZipArchive와 zlib을 모두 사용할 수 없는 환경에서는 관리자의 브라우저가 ZIP 압축 해제를 보조할 수 있습니다.
- 브라우저가 해제한 파일을 그대로 신뢰하지 않고, 서버가 원본 ZIP의 파일 경로, 크기와 CRC를 다시 확인한 뒤 적용합니다.
- 관리자 환경 정보에서 cURL, GD, iconv와 현재 사용되는 ZIP 처리 방식을 확인할 수 있습니다.
PHP 환경 호환성 보강
- mbstring 확장이 없는 서버에서도 iconv 또는 UTF-8 대체 처리로 주요 문자열 기능을 사용할 수 있도록 보완했습니다.
- PHP 7.4부터 8.4까지의 호환 범위를 유지하면서, 일부 함수나 확장 기능이 없는 환경에서 전체 실행이 중단되지 않도록 대체 경로를 추가했습니다.
플러그인 등록 방식 확장
- 기존 플러그인 등록 규칙은 그대로 유지하면서, 플러그인 클래스를 명시적으로 등록할 수 있는 방식이 추가되었습니다.
- 하이픈이 들어간 플러그인 이름도 실제 클래스와 정상적으로 연결할 수 있습니다.
- 서드파티 플러그인 하나가 로딩에 실패해도 다른 플러그인과 에디터 본문은 계속 사용할 수 있습니다.
에디터 접근성과 키보드 조작 개선
- 공통 팝업에 포커스 진입, Tab 순환, Escape 종료와 이전 버튼으로의 포커스 복귀를 적용했습니다.
- 모바일 보조 툴바는 외부 터치와 Escape로 닫을 수 있으며, 열림·닫힘 상태를 보조기기가 정확히 인식하도록 개선했습니다.
- 에디터 본문과 주요 팝업에 필요한 접근성 속성을 보강했습니다.
패치 사항:
GIF 이미지 업로드 오류 해결
- GIF를 업로드할 때 “Image upload could not be completed on this server.”라는 500 오류가 발생할 수 있던 문제를 해결했습니다.
- 업로드 설정이 일부 CMS의 실행 구조 안에서 잘못된 범위로 불러와지면서 이미지 확장자 목록을 찾지 못했고, PHP 경고를 예외로 처리하는 서버에서는 일반적인 업로드 실패가 서버 오류로 바뀌는 것이 원인이었습니다.
- 업로드 허용 정책을 공통 영역에서 안정적으로 읽도록 수정하고, 이미지·파일·비디오 및 관리자 API의 실행 진입 방식도 함께 보완했습니다.
- GIF87a, GIF89a, 투명 GIF, 애니메이션 GIF와 대문자 .GIF를 지원하며, 애니메이션과 투명도를 유지하기 위해 GIF를 다른 이미지 형식으로 변환하지 않고 원본 그대로 저장합니다.
- 손상된 GIF나 다른 형식의 파일을 GIF로 위장한 경우에는 일반 서버 오류 대신 올바른 파일 형식 오류를 표시합니다.
텍스트 덮어쓰기 후 커서가 문서 끝으로 이동하는 문제 해결
- 선택한 텍스트를 교체하거나 AI 기능으로 본문을 다시 작성한 뒤, 다음 입력이 원래 위치가 아닌 에디터 맨 아래에서 시작되던 문제를 해결했습니다.
- 모달, 비동기 업로드, 본문 정리와 Undo·Redo 과정에서 기존 커서 정보가 무효가 되면 문서 끝을 대신 사용하던 것이 원인이었습니다.
- 단순한 브라우저 선택 객체 대신 문단 위치와 글자 위치를 함께 기록하는 방식으로 변경해, 본문 구조가 바뀌어도 가장 가까운 원래 위치로 커서를 복원합니다.
콘텐츠 블록 삽입 위치 개선
- 문장 중간에서 이미지, 비디오, 파일, 표, 코드 등의 콘텐츠 블록을 추가하면 해당 위치에서 문장이 앞뒤로 나뉘도록 수정했습니다.
- 예를 들어 Hello와 World 사이에서 블록을 삽입하면 Hello, 콘텐츠 블록, World 순서가 되며, 블록이 문서 맨 아래나 현재 문단의 끝으로 이동하지 않습니다.
- 선택한 텍스트가 있는 경우에는 선택 영역을 제거하고 정확히 그 자리에 콘텐츠 블록을 삽입합니다.
콘텐츠 블록 위아래 빈 줄의 Enter 문제 해결
- 이미지나 표 등의 콘텐츠 블록 위아래에 자동으로 생성된 빈 줄에서 Enter를 눌러도 줄바꿈이 유지되지 않거나, 다음 입력이 원래 빈 줄로 돌아가던 문제를 해결했습니다.
- 특히 iPhone과 iPad Safari 등 일부 WebKit 환경에서 빈 문단의 내부 요소가 다시 생성되면서 커서가 이전 위치로 되돌아가는 것이 원인이었습니다.
- 빈 문단을 안정적인 편집 단위로 유지하고, Enter 입력이 끝난 뒤 최종 커서를 확정하도록 수정했습니다.
- 블록 위, 블록 아래, 두 콘텐츠 블록 사이와 문서 마지막 블록 뒤에서도 연속 Enter가 정상적으로 작동합니다.
붙여넣기 동작 개선
- 이미지와 설명 문장을 함께 복사했을 때 이미지만 남고 글이 사라지던 문제를 해결했습니다.
- 표를 붙여넣을 때 표 앞뒤의 문장이 사라지거나 표가 문단 내부에 잘못 들어가는 문제를 수정했습니다.
- 여러 줄 텍스트, 빈 줄, 이미지, 표와 일반 문장이 섞인 콘텐츠의 원래 순서를 최대한 유지합니다.
- 표 셀 안에서 붙여넣은 내용이 에디터 본문 맨 아래로 이동하지 않으며, 셀 안에 다시 표를 붙여넣는 경우에는 안전한 텍스트 형태로 처리합니다.
- 비동기 붙여넣기 도중 팝업이나 플러그인이 포커스를 가져가더라도 최초 붙여넣기 위치를 유지합니다.
Enter, Backspace와 Delete 동작 개선
- 텍스트를 선택한 상태에서 Enter를 누르면 선택 내용을 제거한 위치에서 정상적으로 문단이 나뉩니다.
- Shift+Enter는 새 문단이 아니라 현재 문단 안의 줄바꿈으로 처리됩니다.
- 굵게 등의 서식이 적용된 문장 중간에서 Enter를 눌러도 앞뒤 문장의 서식이 유지됩니다.
- 이미지와 표 같은 콘텐츠 블록 옆에서 Backspace나 Delete를 눌렀을 때 블록 내부 구조가 손상되지 않도록 경계 처리를 보강했습니다.
- 한글을 비롯한 IME 조합 입력 중에는 에디터의 별도 키 처리와 브라우저 입력이 중복 실행되지 않도록 했습니다.
Undo와 Redo 안정화
- 최초 편집 전 상태를 Undo 기준점으로 기록해 첫 번째 Undo에서 본문 구조가 비정상적으로 비워지는 문제를 해결했습니다.
- 빠르게 이어서 입력한 문장은 자연스럽게 하나의 Undo 단위로 처리하고, 붙여넣기와 콘텐츠 블록 삽입은 각각 별도의 작업으로 되돌릴 수 있습니다.
- Undo·Redo 후 커서 위치, 글자 수, 자동저장 상태와 플러그인 블록의 조작 기능을 함께 복원합니다.
- 본문을 다시 해석하는 과정에서 텍스트 노드가 합쳐져도 실제 글자 위치를 기준으로 커서를 되돌립니다.
자동저장 초안 충돌 해결
- 모든 게시물과 에디터가 같은 브라우저 저장 키를 사용해 다른 글의 초안이 잘못 복원될 수 있던 문제를 해결했습니다.
- 현재 페이지, 게시물 주소와 에디터 ID를 기준으로 초안을 분리해 한 페이지에 여러 에디터가 있어도 서로 영향을 주지 않습니다.
- 매 입력마다 저장소에 즉시 기록하지 않고 짧은 간격으로 묶어 저장해 장문 작성 중 브라우저 부하를 줄였습니다.
- 브라우저의 사생활 보호 설정 등으로 저장소 사용이 제한된 경우에도 에디터 전체가 중단되지 않습니다.
서식 적용 위치와 문서 구조 오류 해결
- 툴바나 글자 크기 메뉴를 누르는 동안 본문 선택 영역이 사라져, 서식이 문서 끝이나 다른 글자에 적용되던 문제를 해결했습니다.
- 여러 문단을 선택한 뒤 굵게, 색상, 글자 크기 등을 적용할 때 문단 바깥에 잘못된 서식 태그가 만들어지지 않도록 수정했습니다.
- 굵은 문장의 일부만 굵기 해제했을 때 선택하지 않은 앞뒤 글자까지 함께 해제되는 문제를 해결했습니다.
- 여러 문단 정렬 시 선택된 일반 문단에만 적용하고 이미지, 표와 같은 콘텐츠 블록에는 잘못 적용되지 않도록 했습니다.
링크 편집 문제 해결
- 링크 입력 팝업을 여는 동안 선택 영역을 잃어 링크가 다른 위치에 생기던 문제를 해결했습니다.
- 굵게와 기울임 등의 서식이 적용된 문장을 링크로 만들어도 기존 서식을 유지합니다.
- 여러 문단을 선택한 경우 각 문단의 정상적인 구조 안에서 링크를 생성합니다.
- 링크를 제거할 때 링크 안의 굵게·기울임 서식까지 함께 사라지지 않도록 수정했습니다.
- 외부 링크에는 기본 HTTPS 보정과 새 창 보안 속성을 적용했습니다.
표 작성 동작 개선
- 표 셀을 한 번 클릭했을 때 셀 전체 내용이 강제로 선택되어, 다음 입력으로 기존 내용이 전부 덮어써지던 문제를 해결했습니다.
- 클릭한 실제 글자 위치에 커서가 놓이며, Tab과 Shift+Tab으로 이전·다음 셀을 이동할 수 있습니다.
- 표 셀 안의 Enter, 여러 줄 붙여넣기와 커서 이동이 일반 본문 영역으로 빠져나가지 않도록 분리했습니다.
- 표 플러그인과 링크 카드가 사용자가 직접 만든 연속 빈 줄을 불필요하게 삭제하지 않도록 수정했습니다.
파일·이미지·그림 삽입 위치 문제 해결
- 파일이나 이미지를 업로드하는 동안 사용자가 다른 위치에서 글을 입력해도, 업로드 결과가 문서 끝이 아니라 원래 선택하거나 드롭한 위치에 삽입됩니다.
- 그림 플러그인을 열었다가 취소했을 뿐인데 빈 블록이나 빈 줄이 남던 문제를 해결했습니다.
- 그림은 실제 저장이 완료된 경우에만 원래 커서 위치에 추가됩니다.
협업 작성 중 커서 이탈 해결
- 다른 참여자의 변경사항이나 호스트 인계 내용을 반영할 때 전체 본문이 교체되면서 현재 사용자의 커서가 사라지거나 문서 끝으로 이동하던 문제를 해결했습니다.
- 원격 변경을 반영하기 전에 현재 커서와 스크롤 위치를 저장하고, 새 본문에서 가장 가까운 논리적 위치로 복원합니다.
플러그인 로딩 실패 복구
- 플러그인 로딩에 실패했을 때 버튼이 비활성화된 채로 남거나 로딩 표시가 계속되는 문제를 해결했습니다.
- 하나의 플러그인 오류가 다른 플러그인과 본문 초기화를 막지 않도록 분리했습니다.
- 응답하지 않는 플러그인을 무한히 기다리지 않도록 제한 시간을 적용하고, 실패한 버튼은 다시 사용할 수 있는 상태로 복구합니다.
- 같은 플러그인 훅이 중복 등록되어 제출 내용이 여러 번 변환되는 문제도 방지했습니다.
- 비활성화된 플러그인을 불필요하게 기다리던 초기 지연과 파일 크기 확인을 위한 추가 네트워크 요청을 줄였습니다.
빈 본문 처리 오류 해결
- 외부 연동 기능에서 빈 문자열을 전달해도 기존 본문이 지워지지 않던 문제를 해결했습니다.
- 전체 내용을 삭제한 뒤에도 즉시 다시 입력할 수 있는 빈 문단을 유지합니다.
- 라이믹스의 setData, insertHtml과 게시물 제출용 숨은 입력값도 최신 본문 상태와 일치하도록 보완했습니다.
브라우저별 플러그인 호환성 개선
- 검색 플러그인은 브라우저 저장소를 사용할 수 없는 경우에도 대체 방식으로 동작합니다.
- 밈 플러그인은 IntersectionObserver를 지원하지 않는 브라우저에서도 목록을 표시합니다.
- 검색과 비디오의 Enter 입력은 오래된 keypress 대신 브라우저 호환성이 높은 keydown을 사용합니다.
- 그림, 협업, AI 등의 중첩 팝업이 다른 플러그인의 팝업을 잘못 닫거나 포커스를 빼앗는 문제를 줄였습니다.
CMS 경로 및 업로드 간섭 문제 해결
- 서브폴더 설치, T2Pack 데이터 슬롯 실행과 CMS 파일 구조가 겹치는 환경에서도 실제 T2Editor 설치 위치와 CMS 루트를 구분하도록 수정했습니다.
- 라이믹스 업로드와 선택적 외부 연동이 서로의 요청을 잘못 가로채지 않도록 우선순위를 정리했습니다.
- 한 페이지에 여러 라이믹스 에디터가 있을 때 각 에디터의 업로드 식별 정보가 서로 섞이지 않도록 했습니다.

## 배포 설명

T2Editor 10.4.0은 크게 두 가지 방향으로 개선됐습니다. 하나는 사이트 운영자가 에디터를 설치하고 관리하기 편하게 만든 부분이고, 다른 하나는 실제로 글을 쓸 때 느껴지는 기능 개선입니다. 관리자 입장에서는 설치할 때 뭘 놓쳤는지 알려주는 안내, 모든 설정을 한곳에서 관리하는 화면, 클릭 몇 번으로 업데이트하고 문제 생기면 되돌리는 기능, 필요한 확장 기능을 검색해서 설치하는 마켓이 새로 생겼습니다. 글 쓰는 사람 입장에서는 파일을 끌어다 놓으면 바로 업로드되는 기능, 표에서 셀을 합치고 나누는 기능, 편집창 크기를 원하는 만큼 늘리는 기능이 추가됐습니다. 그 외에도 이미지 업로드가 더 안정적으로 되고, 여러 언어 지원이 매끄러워지고, 다크 모드가 제대로 작동하도록 다듬어졌습니다.

처음 설치할 때 놓친 설정을 자동으로 확인해주는 안내 화면

서버 상태를 자동으로 점검해서 문제를 미리 알려주는 기능

처음 설치할 때 나오는 안내 화면은, 관리자 기능이 켜져 있는지, 비밀번호는 설정했는지, 파일을 저장할 폴더에 쓰기 권한은 있는지, 서버가 필요한 기능을 지원하는지 등을 자동으로 확인해줍니다. 내 서버 환경에 맞춰 어떤 명령어를 입력하면 되는지, FTP 프로그램으로는 어떻게 설정하면 되는지도 함께 알려줍니다. 이런 필수 설정이 끝나지 않으면 잘못된 상태로 에디터가 쓰이는 걸 막기 위해 잠시 편집 기능이 잠깁니다.

통합 관리 페이지에서는 버전 정보, 라이선스 상태, 업데이트, 확장 마켓, 기본 설정, 부적절한 이미지 필터, 어떤 기능을 켜고 끌지, 툴바 아이콘, 화면 크기별 메뉴 구성, 업로드 가능한 파일 종류와 용량, 비밀번호 같은 보안 설정을 한곳에서 볼 수 있습니다. 다크 모드와 휴대폰 화면에서도 잘 보이도록 만들어졌습니다.

자동 업데이트는 새 버전이 나왔을 때 어떤 파일이 바뀌는지, 용량은 얼마나 되는지, 기존에 수정해둔 파일과 충돌할 부분은 없는지 미리 보여줍니다. 최신 버전이 아니라 특정 버전을 골라 설치하거나, 지금 쓰는 버전을 다시 설치하는 것도 가능합니다. 안전을 위해 기본적으로는 원래 파일을 직접 건드리지 않고 별도 공간에 새 버전을 설치한 뒤 전환하는 방식을 씁니다. 이렇게 하면 문제가 생겨도 이전 상태로 바로 되돌릴 수 있습니다.

원래 폴더에 직접 업데이트하는 방식도 선택할 수 있는데, 이 경우 직접 수정했던 파일과 충돌하는 부분은 관리자가 확인한 뒤 유지할지 바꿀지 고를 수 있고, 업데이트 전 파일은 자동으로 백업됩니다. 업데이트 파일을 적용하기 전에는 손상되거나 위험한 파일이 없는지 검사하고, 실제로 적용하거나 되돌릴 때는 비밀번호를 다시 확인합니다.

확장 마켓에서는 필요한 기능(플러그인)이나 언어팩을 검색해서 설치할 수 있습니다. 설치 전에 어떤 기능인지, 어떤 버전이 필요한지 확인할 수 있고, 설치한 목록은 따로 관리하거나 삭제할 수 있습니다. 공식적으로 검증된 마켓과 그 외 마켓이 구분돼 표시되며, 믿을 수 있는 곳이라면 관리자가 직접 추가로 등록할 수도 있습니다. 설치 전에는 항상 안전성 검사를 거칩니다.

파일 업로드는 이제 컴퓨터에서 파일을 끌어다 글쓰기 창에 놓기만 하면 됩니다. 이미지, 영상, 문서, 압축파일 등 종류에 맞게 자동으로 삽입되고, 여러 개를 한 번에 올릴 수도 있습니다. 허용되지 않은 파일이나 용량 초과 파일이 있으면 어떤 파일이 문제인지 바로 알려줍니다.

표 기능에는 여러 칸을 하나로 합치거나 다시 나누는 기능이 생겼습니다. 칸을 선택해서 합칠 범위를 지정하면 되고, 합쳐진 칸도 다시 나눌 수 있습니다.
행이나 열을 추가·삭제해도 합쳐진 칸이 깨지지 않도록 개선됐고, 엑셀로 내보낼 때도 위치가 어긋나지 않게 됐습니다. 다크 모드에서 표가 이상하게 밝게 보이던 문제도 고쳐졌습니다.

글쓰기 창 높이는 관리자가 기본 크기를 정할 수 있고, 컴퓨터를 쓰는 사용자는 마우스로 아래쪽을 끌어서 원하는 크기로 늘릴 수 있습니다. 한 번 조절하면 다음에 접속할 때도 그대로 유지됩니다. 휴대폰에서는 실수로 화면이 조작되는 걸 막기 위해 이 기능이 꺼져 있습니다.

이미지 업로드는 아직 업로드가 끝나지 않았거나 이미지 주소에 문제가 있으면 글이 게시되지 않도록 막아줘서, 깨진 이미지가 그대로 올라가는 일이 줄었습니다. 업로드에 실패해도 깨진 표시가 계속 남지 않고 무엇이 문제인지 바로 알려줍니다. 움직이는 GIF는 정지 이미지로 바뀌지 않고 원래대로 저장되며, 서버 환경이 다소 부족해도 업로드 중 오류로 멈추는 일 없이 안전하게 저장되도록 개선됐습니다.

부적절한 이미지를 걸러주는 필터는 이제 필요한 파일이 프로그램 안에 포함돼 있어서 외부 서버에 의존하지 않고 더 안정적으로 작동합니다. 특정 설치 환경에서 필터가 아예 작동하지 않던 문제, 움직이는 GIF를 검사할 때 오류가 나던 문제도 해결됐습니다. 어떤 방식으로 검사를 실행할지는 관리자가 설정할 수 있습니다.

여러 언어 지원은 필요한 언어만 먼저 불러오도록 바뀌어서 처음 페이지가 열리는 속도에 영향을 덜 주게 됐고, 특정 기능의 번역이 빠지거나 잘못돼 있어도 다른 기능에는 영향을 주지 않도록 분리됐습니다.

화면 크기에 따라 메뉴 버튼이 깨지던 문제, 메뉴를 숨겼다가 다시 열 때 배치가 흐트러지던 문제가 고쳐졌고, 관리자가 화면 크기별로 어떤 버튼을 어떻게 묶어서 보여줄지 직접 설정할 수 있습니다. 아이콘도 내장된 목록에서 바로 골라 바꿀 수 있습니다.

다크 모드는 접속할 때마다 기기나 브라우저의 현재 설정을 다시 확인해서, 예전에 저장해둔 설정 때문에 화면이 이상하게 보이는 문제가 없어졌습니다. 관리자는 항상 라이트 모드나 다크 모드로 고정해둘 수도 있습니다.

마지막으로, 비밀번호나 운영 관련 정보처럼 민감한 데이터는 외부에서 직접 접근할 수 없는 안전한 곳으로 옮겨 보관하도록 개선됐고, 관리 페이지에서는 서버 상태를 자동으로 점검해서 업데이트나 확장 기능 설치에 문제가 없는지 미리 확인하고, 캐시나 업로드 용량 같은 설정도 손쉽게 관리할 수 있습니다.

AI 기능 강화
글쓰기, 채팅, 문서 재구성 결과가 실시간 스트리밍으로 표시되며, 응답이 중단되어도 이미 생성된 내용은 최대한 보존됩니다. 처리 단계와 최종 답변이 구분되고, 여러 단계의 검토·재작성 과정도 안정적으로 처리됩니다. 예상 사용량과 사용 가능 여부가 명확히 표시되며, 이미지 삽입·검색·문서 통계 등의 확장 도구를 연속으로 사용할 수 있도록 연동 구조가 개선되었습니다. 사용자 언어에 맞춘 응답 기준이 강화되었고, 문서 전체를 다시 쓰지 않고 특정 문장 교체, 원하는 위치 삽입, 직전 편집 취소를 수행하는 정밀 편집 도구가 추가되었습니다. AI 메모리는 이름, 선호 말투, 반복 지시, 프로젝트 맥락 등 이후 대화에 유용한 정보를 판단해 저장할 수 있습니다.

현재 영상 주소 복사, 현재 재생 시점부터 시작하는 공유 링크 생성, 지원 기기에서의 운영체제 기본 공유 메뉴 사용이 가능합니다. 공유 링크를 열면 지정된 재생 시점으로 자동 이동합니다.

HLS P2P 재생
HLS 영상을 시청하는 이용자들이 영상 데이터를 브라우저 간에 나눠 전송할 수 있습니다. 연결된 이용자가 있으면 원본 영상 서버의 트래픽을 줄일 수 있고, P2P 연결이 불가능하거나 오류가 발생하면 일반 스트리밍으로 자동 전환됩니다. 연결된 피어 수와 P2P 전송 비율도 확인할 수 있습니다.

영상 실시간 채팅
같은 영상을 보는 이용자끼리 브라우저 간 P2P 연결로 실시간 대화가 가능합니다. 영상별 자동 채팅방 구성, 시청자 수 표시, 닉네임 변경, 최근 채팅 기록 공유, 채팅을 영상 위에 표시하는 탄막 기능, 채팅 호스트 이탈 시 자동 재선출을 지원합니다.

라이믹스 호환성 추가
라이믹스 2.1.x 에디터 스킨 연동 구조가 추가되어 편집기 설정과 다중 에디터 인스턴스, 기존 본문 필드와의 자동 연동, 기본 첨부파일 업로더 및 자동저장·업로드 세션 연동을 지원합니다. 업로드한 파일은 라이믹스 파일 모듈과 첨부파일 목록에 정상 등록되며, 확장자 없는 다운로드 주소도 이미지·파일·영상에서 처리됩니다. T2Editor 영상 플레이어의 iframe 주소도 자동 허용 처리되며, 파일은 T2Editor의 별도 저장소가 아닌 라이믹스 파일 모듈을 통해 관리됩니다.

편집 안정성 개선
여러 서식이 섞인 문단에서 Enter를 눌렀을 때 서식과 커서 위치가 잘못되던 문제, 붙여넣기 후 서식과 커서가 어긋나던 문제, 이미지·영상·파일·표·코드·그림 블록 앞에서 Backspace를 눌렀을 때 블록 구조가 손상되던 문제가 수정되었습니다. 선택 영역 없이 일부 서식 명령을 실행할 때 발생하던 오류도 방지되었고, 굵게·기울임·밑줄·취소선·글자색·배경색 처리는 최신 Selection·Range 기반 구조로 전환되었으며, 이전 브라우저 호환을 위한 보조 방식도 유지됩니다. 코드 블록 입력 기능에는 최신 브라우저용 텍스트 삽입 대체 처리가 추가되었습니다.

자동저장 및 복원 개선
자동저장 데이터에 저장 시각이 함께 기록되고, 오래된 자동저장 내용은 복원 전 사용자 확인을 거칩니다. 기존 버전의 자동저장 데이터도 계속 읽을 수 있으며, 자동저장 복원·실행 취소·다시 실행·외부 콘텐츠 적용 후 편집 버튼이 사라지던 문제가 수정되었습니다. 복원 이후 각 플러그인의 편집 컨트롤도 자동으로 다시 연결됩니다.

플러그인 로딩 안정화
동일한 플러그인 스크립트가 즉시 로딩과 지연 로딩으로 중복 실행되던 문제, 클래스 중복 선언이나 네트워크 요청 중복 발생 문제가 수정되었습니다. 백그라운드 로딩 중 버튼 클릭 시 발생하던 충돌과 초기화 오류 시 로딩 표시가 남아있던 문제도 해결되었습니다. 설정 파일을 기반으로 확장 플러그인을 자동 등록할 수 있는 구조도 추가되었습니다.

표 편집 개선
일반 붙여넣기 이벤트를 표 붙여넣기 기능이 잘못 가로채던 문제, 표 붙여넣기 후 브라우저 기본 붙여넣기가 재실행되어 내용이 중복되던 문제가 수정되었습니다. 큰 표 선택 시 미리보기 영역이 잘리거나 과도하게 커지던 문제가 개선되었고, 미리보기는 매번 새로 만들지 않고 재사용되며, 다크 모드에서 표 미리보기의 테두리·배경도 정상 표시됩니다.

이미지 업로드 화면 개선
모바일 이미지 업로드 창을 아래로 드래그해 닫을 수 있으며, 닫기 애니메이션은 배경 전체가 아닌 업로드 창에만 적용됩니다. 애니메이션 축소 설정 기기도 지원하며, 일부 화면에서 업로드 창 너비와 여백이 화면을 벗어나던 문제도 수정되었습니다.

게시된 영상 복원 및 표시 개선
게시판이나 CMS의 HTML 보안 필터가 영상 iframe이나 일부 속성을 제거하더라도, 저장된 영상 링크와 데이터를 이용해 보기 화면에서 플레이어를 다시 구성할 수 있도록 보완했습니다. 영상 크기와 비율, 에디터 재진입 시 편집 상태가 복원되고, 라이믹스의 확장자 없는 영상 다운로드 주소도 지원됩니다. 콘텐츠 너비를 넘지 않도록 영상 최대 크기가 제한되며, 모바일 브라우저의 주소창과 안전 영역을 고려해 플레이어 높이와 하단 여백이 처리됩니다. 페이지 이탈 시 P2P 연결도 정상적으로 종료됩니다.

기타 수정 사항
콘텐츠를 반복 편집하거나 재발행할 때 동일한 스타일시트가 중복 추가되던 문제, 실행 경로에 따라 업로드 설정 파일이 로드되지 않던 문제, 글자 수 표시 요소가 없는 구성에서 입력 이벤트가 중단되던 문제가 수정되었습니다. 에디터 버전 정보를 눌러 실행 환경, 미디어 블록 크기, 저장 필드 내용을 확인할 수 있는 진단 정보 창이 추가되었고, 협업 기능의 상태 메시지·도움말·임시 닉네임·알림도 선택된 언어에 맞춰 갱신됩니다. PDF와 오디오 플레이어의 오류 메시지 및 접근성 안내 문구도 정리되었습니다.

10.2.0부터 T2Editor AI는 단순한 플러그인이 아닌, T2Editor 위에서 AI가 에디터를 쉽게 조작하고, 환각에 적게 걸릴 수 있도록 제어 및 각종 도구들을 사용할 수 있도록 돕는 공통 베이스 시스템(t2llm.js, t2ai_core.js)으로 진화하였습니다,
또한 기존 T2Editor AI 구버전의 경우 모든 조작이 dsclub서버를 경유해야 했던 것을, T2Editor AI자체 Tool 기능으로 따로 뺐으며 T2Editor AI의 플랫폼화를 통해 다른 서드파티 Ai플러그인들도 T2Editor을 조작할 수 있게 하는 기능 개발이 더욱 수월해졌습니다. 그리고 llm api 셀프 호스팅이 가능하도록 변경 및 T2Editor AI의 모듈화를 진행하여 쉽게 T2Editor AI를 위한 각자의 Tool(도구)를 추가 및 삭제할 수 있습니다.
*Skill(Skill-lite) 기능도 지원합니다.
*이번 10.2.0버전 부터 새롭게 추가되는 ai_complex 플러그인(= T2Editor complex AI)은 클로드 웹 채팅 인터페이스 벤치마킹하여 유저가 익숙하게 사용할 수 있도록 하였습니다.
